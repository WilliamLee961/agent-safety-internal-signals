# 给其他 Codex 的交接提示词

打开或克隆本仓库后，可以直接粘贴：

```text
请先阅读 AGENTS.md、README.md、CURRENT_STATE.md，再读 docs/evidence.md 和 docs/reproduction-plan.md。

这是基于我已有 LCIC 幻觉论文开展毕业设计第二项工作的研究仓库。当前候选目标是探索内部信号能否辅助 Agent 安全核验，在维持攻击防护的同时减少误干预，提高任务完成率。

目前只有文献梳理和作者公开日志核查，尚未重新运行模型，没有新方法结果。请不要把读取作者日志称为复现，也不要把模型高置信度当成安全授权。

上一项未完成任务是选择一篇高影响力、足够近期、适合当前目标的 Agent 安全综述，并说明可核实的影响力、覆盖范围和阅读重点。随后应按复现计划确认真实问题，检查近期强防御是否已解决，再讨论 LCIC 迁移。

请先用几句话说明你理解的当前状态，然后继续完成下一项可独立推进的工作。若实际模型实验需要未知的 GPU、端点或预算，请先完成文献和代码准备，再询问缺失资源。

工作完成后更新 CURRENT_STATE.md 和 docs/progress.md，明确实际运行了什么、只查看了什么、哪些判断仍是假设。保留我的已有修改，不要自行公开仓库或上传未发表论文原稿。
```

若本次只做导师交流，可补充：“我还没精读论文，请用具体例子解释，避免堆术语，不要把候选方法讲成已经完成的成果。”

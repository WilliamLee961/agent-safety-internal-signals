# 当前阶段的导师交流讲稿

老师，我想汇报一下毕业设计第二部分的初步方向。目前仍在调研阶段，还没有确定最终方法，也没有新的实验结果。

前期 LCIC 研究利用模型生成过程中的内部信号判断幻觉风险，并结合相应方法干预。第二部分我倾向转向 Agent 安全，把关注对象从生成回答进一步扩展到工具动作和任务执行。

Agent 需要不断读取外部信息，再决定下一步操作。网页或邮件中的恶意内容可能被误当成指令，诱导用户没有授权的动作。但完成正常任务也需要一部分外部流程要求，比如购买商品前的账户验证。所以，防御不能简单地把外部要求全部删除。

目前有一个具体证据来自 AgentDyn 的评测。在其 GPT-4o 设置下，ProtectAI 将攻击成功率从 37.80% 降到 0.85%，但无攻击时的任务完成率也从 53.33% 降到 0%。作者认为，这与难以区分合法流程要求和恶意注入有关。这是作者在特定动态环境中的结果，还不是我们自己的复现，也不能概括所有防御。

因此，目前的候选问题是：如何维持攻击防护，同时减少安全检查对正常任务的误干预。与前期工作的联系在于，内部信号可能提供额外判断依据，例如帮助决定哪些不确定位置值得进一步核验。但模型自信不代表动作安全，原来的幻觉分数也不能直接作为权限判据。

我准备先通过近期综述建立完整的 Agent 安全框架。目前还在筛选合适的主读综述，影响力和文献覆盖范围需要进一步核实。之后先复现 AgentDyn 中正常任务被防御影响的现象，分析具体失败原因，再引入近期强方法，确认是否仍有残余问题。

只有问题确认之后，才进一步设计新的核验机制，并比较加入内部信号前后的差别。评价会同时看攻击成功率、正常任务完成率、受攻击任务完成率和额外成本，避免靠一律拒绝降低攻击成功率，或靠额外计算制造不公平优势。

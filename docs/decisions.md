# 研究决策记录

## D001 先证实问题再设计方法

日期：2026-09-23，整理自此前讨论。

用户要求先找到真实、可重复、未被已有方法充分解决的问题。Agent 热度与 LCIC 可复用性不能替代问题证据。综述阅读和最小复现优先于最终题目、训练和贡献承诺。

## D002 区分幻觉与 Agent 安全

日期：2026-09-23，整理自此前讨论。

当前研究“安全防御误干预正常任务”，而非已证实的“幻觉缓解导致合法动作失效”。任务完成与攻击成功独立评价；不使用“动作幻觉率”代替 ASR。

## D003 内部信号是可选证据

日期：2026-09-23，整理自此前讨论。

LCIC 的信号提取经验可迁移，但原分数阈值、安全标签、聚合单位和训练反馈均需重新验证。权限是硬约束。若消融显示没有新增价值，移除信号或调整方向，不强行拼接前期工作。

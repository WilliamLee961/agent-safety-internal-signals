# 研究问题与 LCIC 衔接

## 当前问题

合法用户要求 Agent 完成任务，Agent 从外部工具返回获取信息。攻击者可能控制其中指定片段，诱导未授权动作。防御必须阻止越权，同时保留完成任务所必需的外部信息与流程。

“读取网页并将摘要发给指定邮箱”中，网页可提供摘要内容，但不应自行更改收件人。“购买商品”中，可信账户流程提出验证要求可能是合法步骤，不能仅因它来自外部就过滤。两者都是讲解例子，不代表我们已经运行过的实验。

## 三层研究问题

1. **问题层：** 近期强防御是否仍会在动态正常流程中产生可重复的误干预？区分能力不足、实现适配、工具错误与防御引发的失败。
2. **方法层：** 在相同资源预算与相近 ASR 下，跨步证据或选择性复核能否改善任务完成？先建立不使用内部信号的合理版本。
3. **信号层：** 相对于任务、动作、来源和外部诊断信息，模型内部信号是否提供稳定的新增价值？

“长流程可能累计误判”是待检验机制。独立且等概率的每步错误会产生累计风险只是数学直觉；真实轨迹有相关性、恢复机会和任务难度差异，不能把直觉当实测定律。

## 与前期论文的关系

| 前期基础 | 候选迁移用途 | 必须验证 |
| --- | --- | --- |
| token 置信度 | 识别动作生成不稳定位置 | 是否只是工具陌生或参数复杂 |
| 注意力聚焦 | 辅助观察工具返回与动作关系 | 注意力不等于因果、可信来源或授权 |
| 中间层与最终层分布差异 | 辅助核验信号 | 是否跨任务、工具、模型有效 |
| 尾部聚合 | 避免局部风险被平均掩盖 | 聚合单位、方向、阈值重新标定 |
| GRPO 与 BoN 经验 | 有可靠反馈后训练或选择候选动作 | 不奖励一律拒绝，不泄露未来评价 |

原 LCIC 的 S_LCIC 越低对应较高幻觉风险，但不能直接转成 Agent 安全阈值。高置信度也可能伴随攻击执行。黑盒 API 通常无法取得全部内部特征；通过 API 使用开源权重模型也不保证获得内部状态。

## 当前不能宣称的新颖性

PACT 已研究参数级来源与授权；PIPES 已研究观察单元筛查；AttriGuard 已研究动作反事实归因和正常差异容忍；AgentSentry 已研究时间诊断与净化续跑；StepGuard 已研究动作级监督及安全效用平衡；EvoSafeHarness 已研究领域和模型特定的运行时优化。创新须来自可验证的残余条件及方法差异，不能只是拼接模块。

## 成立与否定条件

- 问题成立：统一实现下能重现误干预，且解释不能被无防御能力失败或程序错误替代。
- 方法成立：同预算、相近 ASR 下稳定改善效用，对强基线和合理阈值有优势。
- 信号成立：去掉信号后表现下降，且迁移后仍有效，收益不是额外调用或标签泄漏带来的。
- 若其中任一步失败，修改贡献范围；不得写成已完成成果。

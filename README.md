# Agent Safety with Internal Signals

从 LCIC 幻觉研究出发，探索模型内部信号能否辅助 Agent 安全核验，在保持攻击防护水平的同时减少误干预，提高任务完成率。

**当前阶段：选题调研与公开证据核查。尚未完成模型运行复现，尚无新方法实验结果。** 该方向是候选研究问题，不是已确认的创新点。

## 我们到底想研究什么

**问题：** 工具型 Agent 需要利用外部信息完成任务，但外部内容也可能携带间接提示注入。部分防御在阻止攻击的同时，会过滤合法流程要求或拦截正常动作，使任务无法完成。

**候选假设：** LCIC 中使用的置信度、注意力聚焦、层间分布差异等内部信号，可能提供额外诊断信息，帮助安排复核或识别不可靠的安全判断。是否有效，需要在同模型、同预算、相近攻击成功率的条件下验证。

**不能直接做的推断：** 高置信度不等于安全，低置信度不等于攻击；原 LCIC 的幻觉阈值不能直接作为动作授权阈值。权限规则不因模型自信而放宽。

研究目标使用 ASR、正常任务完成率、受攻击任务完成率和成本；不把它们改称“动作幻觉率”。新工作关注 Agent 安全与误干预，和幻觉相关但不等同。

| 方法 | 正常任务完成率 ↑ | 受攻击任务完成率 ↑ | ASR ↓ |
| --- | ---: | ---: | ---: |
| 无防御 | 53.33% | 55.52% | 37.80% |
| ProtectAI | 0.00% | 0.56% | 0.85% |
| DRIFT | 30.00% | 27.09% | 0.83% |

[原表](https://arxiv.org/html/2602.03117v3#S3.T3) · [作者解释](https://arxiv.org/html/2602.03117v3#S4.SS2)。总体值是三个任务套件的平均。作者默认攻击和自动完成任务的系统提示等设置见 [证据说明](docs/evidence.md)。这些结果不能外推为所有防御在所有部署中均失效。

## 本仓库现在能运行什么

目前只提供**公开日志审计工具**，不包含新的 Agent 防御实现，也不调用付费模型。

需要 Python 3.10+，仅用标准库。首次获取四条固定版本的官方日志并生成审计结果：

```bash
python scripts/audit_public_logs.py --fetch --output data/derived/public-log-audit.json
```

之后使用本地缓存，不重新下载：

```bash
python scripts/audit_public_logs.py --output data/derived/public-log-audit.json
```

执行此脚本只验证作者日志的字段与过滤标记，不重放 Agent、不执行工具动作，也不能单独建立误干预的完整因果结论。运行缓存和派生输出默认不入 Git；本次交接保存的结果见 [已核查记录](docs/evidence/public-log-audit.json)。
